How to set up voice cloning ›
  1. Put voiceflow_tts_server.py and Start-VoiceFlow-TTS.bat in the same folder as this app.
  2. Double-click Start-VoiceFlow-TTS.bat. The first run installs Python packages (≈3 GB) and downloads the Chatterbox model (≈2 GB). Needs Python 3.11; an NVIDIA GPU makes it fast.
  3. Leave that window open, record or upload your voice above, then pick My cloned voice as engine.
  4. Everything stays on your computer. Chatterbox adds an inaudible watermark to its audio.
